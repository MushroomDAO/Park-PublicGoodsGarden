三条服务通道的账

商店的两半遵循两种经济学。这是整个产品能否成立的唯一关键判断。

通道交付物边际成本定价谁付算力费
① 下载代码、模型权重、构建产物≈ 0免费无限无人
② BYOK推理结果= 0（对你）免费你自己
③ 社区 API推理结果> 0按量计费你，按实际用量
BYOK 不是附加功能，它是让「¥9.9 终身」在数学上成立的支点。
Park 提供算力 → 边际成本 > 0 → 必须计量 → 不可能终身免费。
用户自带密钥 → 边际成本 = 0 → 可以终身免费 ✅

BYOK · 自带密钥

填入你自己的 API Key，或指向本地模型服务。密钥只存在你的浏览器里。

🔒 密钥仅保存在你的浏览器本地存储中，永远不会上传到 Park。这是 BYOK 的全部意义——一旦密钥经过我们的服务器，它就不再是 BYOK 了。

我的席位

0 / 4

每个席位绑定一台硬件（Secure Enclave / TPM / Keystore 中的不可导出私钥）。席位用于反滥用，不用于限制你使用软件——代码本来就是开源的。

在按量计费下，多人共用一个席位不造成收入损失——用得多就付得多。
所以席位不是收费闸门，而是反滥用机制：它保护的是不计量的免费额度，不是「使用行为」。

这里为什么没有 DRM

公共物品是 Apache 2.0 的。任何人只要有技术能力，都可以直接拿走代码使用，甚至可以复制我们整套体系——这是对的，而且我们接受。

因为复制的成本结构决定了它不可规模化。想复制的人需要自建：

  • KMS 与密钥管理
  • 自动更新管道与签名分发
  • 算力与推理（真金白银的边际成本）
  • 节点网络与网络效应（无法复制，只能长出来）
  • 身份、信誉、争议仲裁
Park 的护城河是「网络效应 + 更新管道 + 托管服务 + 信任」，不是代码。
破解者能拿走的是工具，拿不走的是电网。
